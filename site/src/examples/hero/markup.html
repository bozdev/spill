01

Native scroll

The viewport really scrolls: a finger's momentum, a trackpad, find-in-page and the keyboard work as on any scrolling box.

02

Embla's API

The same options, methods, events and plugin shape — code written for Embla mostly runs as it is.

03

No dependencies

And no stylesheet. What it needs it writes inline, and takes away again on destroy.

04

Small

The core is under 5 KB gzip — the browser does the snapping, the momentum and the drag on a touch screen.

05

By attributes

Write the markup and it builds itself. This carousel has no script of its own — only attributes.
